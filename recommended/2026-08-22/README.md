- **축**: 기관 간 일반화, 파운데이션 모델의 편향과 강건성
- 84만 장으로 학습, 12개 공개 데이터셋 8.2만 장으로 검증하며 연령·성별·인구집단 편향을 정량 분석. 본 코호트의 균형 잡힌 성비(136:136)와 넓은 연령대(9~87세), 5개 기관 분산 구조가 유사한 층화 분석을 가능케 함.

### 2. 다기관 척추 영상 LLM 진단 평가
- **venue**: npj Digital Medicine · [DOI](https://doi.org/10.1038/s41746-026-03133-z)
- **축**: 기관 간 일반화, 저빈도 소견에서의 성능 저하
- 3개 기관 20,277건 판독문으로 4개 LLM 비교, 저빈도 질환에서 정밀도 19~42%p 하락하는 롱테일 문제 확인. 본 코호트도 5개 기관 분산 + No Finding 편중(53%) 구조로 동일한 위험 구조를 가짐.
- **한계**: 대상이 척추·텍스트 판독문 기반이라 흉부 X-ray 영상 진단에 직접 일반화 불가.
